# Chess (Roblox, Classic + Abilities modes)

Before working, read `Chess/Home.md` (Obsidian vault), then `Chess/Open Questions.md`: confirm the
platform and get the abilities from the user before building ability code. After working, add
`Chess/Changelog/YYYY-MM-DD Title.md`, link it at the top of the Home changelog, and update
`Chess/Current State.md` and `Chess/Next Steps.md`.

Tools: `python push.py` pushes `src/` into Studio (Edit mode); `python tools/luau_check.py <files>`
syntax-checks. Studio MCP gotchas are in `Chess/Tooling and Studio Gotchas.md`.
